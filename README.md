# 🦖 恐龍大冒險 (Dino Adventure)

這是一個使用 HTML5 Canvas、CSS3 和 JavaScript 開發的精美恐龍冒險遊戲。

## 🎮 遊戲玩法
- 按下 **空白鍵 (Space)** 或 **點擊螢幕** 來跳躍。
- 避開前方出現的障礙物。
- 隨著分數增加，速度會越來越快！

## 🚀 如何在 GitHub 上發布？

如果你想讓朋友也能玩到這個遊戲，請按照以下步驟操作：

1. **建立 GitHub 儲存庫**：
   - 登入你的 [GitHub](https://github.com/) 帳號。
   - 點擊右上角的 `+` 號，選擇 `New repository`。
   - 命名為 `dino-adventure`，然後點擊 `Create repository`。

2. **上傳程式碼**：
   - 在你的電腦上打開終端機（Terminal 或 CMD）。
   - 進入你的專案資料夾。
   - 執行以下指令：
     ```bash
     git init
     git add .
     git commit -m "Initial commit: Dino Adventure Game"
     git branch -M main
     git remote add origin https://github.com/你的使用者名稱/dino-adventure.git
     git push -u origin main
     ```

3. **啟動 GitHub Pages**：
   - 在 GitHub 儲存庫頁面，點擊 **Settings** (設定)。
   - 在左側選單點擊 **Pages**。
   - 在 "Build and deployment" 底下，選擇 `Deploy from a branch`。
   - 分支選擇 `main`，資料夾選擇 `/(root)`。
   - 點擊 **Save**。

幾分鐘後，你就可以透過 `https://你的使用者名稱.github.io/dino-adventure/` 玩到你的遊戲了！

## ✨ 特色
- **精美視覺**：現代化的暗色調設計與霓虹效果。
- **響應式設計**：自動適應不同螢幕大小。
- **本地紀錄**：會自動儲存你的最高分數。
