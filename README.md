# 🦖 恐龍大冒險 (Dino Adventure)

🎮 **線上遊玩：** https://lingaoscar.github.io/dino-adventure/

這是一個使用 HTML5 Canvas、CSS3 和 JavaScript 開發的精美恐龍冒險遊戲。

## 🎮 遊戲玩法
- 按下 **空白鍵 (Space)** 或 **點擊螢幕** 來跳躍。
- 避開前方出現的障礙物。
- 隨著分數增加，速度會越來越快！

## 🚀 部署

詳見 [doc/github-pages.md](doc/github-pages.md)。

## ✨ 特色
- **精美視覺**：現代化的暗色調設計與霓虹效果。
- **響應式設計**：自動適應不同螢幕大小。
- **本地紀錄**：會自動儲存你的最高分數。
